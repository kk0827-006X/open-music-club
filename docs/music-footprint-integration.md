# 音乐足迹功能说明

音乐足迹用于记录成员的开播快照，并生成时间轴、里程碑、分享卡片、点赞和评论。功能来源为 `cxbcrj/open-music-club-wqh` 的 `8145f62c8671521ba617a4eb3af73825588e2aa8` 根目录 `music footprint` 接入包；没有直接合并整个 Fork、覆盖共享文件或修改原网易云/本地音源、档案墙算法和播放器动效。

## 数据与权限

启动时幂等创建六张表：

- `playback_events`：按用户、来源和曲目保存开播快照，索引支持时间轴与同曲去重。
- `footprint_notes`：每个事件一篇随笔；复合外键保证随笔与事件属于同一用户。
- `footprint_cards`：标题、事件 ID 和生成时的 JSON 快照。
- `footprint_posts`：用户显式发布的卡片，一张卡片最多一条分享；复合外键保证作者一致。
- `footprint_likes`：成员对分享的唯一点赞。
- `footprint_comments`：分享下的评论。

私有记录、随笔与卡片只能本人访问和修改；显式分享后的卡片及其中随笔才向其他已登录成员可见，广场不是匿名公网入口。分享、卡片和评论仅本人可删除，外键级联清理关联数据。

所有足迹接口经过现有完整登录检查：密码通过但 2FA 未完成、账号被禁用、失效 Session 均不能访问。写请求复用全局 CSRF/Origin 检查，不另建登录系统，也不放宽 Cookie、CORS、代理或 HTTPS 配置。新增 `footprint` 限流命名空间：每用户 15 分钟最多 180 次写操作，使用既有生产 Redis Store 工厂；读请求仍受既有全局限流。错误响应保持脱敏，校验错误附带请求 ID。

限制：每用户最多 100000 条开播记录、50 张卡片，每张卡片选择 1–12 条本人记录，每条分享最多 500 条评论。到达上限返回明确错误，不静默删除历史；每页最多 50 条，时间轴 offset 覆盖记录上限，其他列表 offset 最多 10000。

## API

前缀统一为 `/api/footprint`，响应沿用 `{ success, ... }`。

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| POST | `/events` | 上报开播；来源 local/netease，正整数 sourceId、标题/歌手/专辑/安全封面与 durationMs |
| GET | `/timeline?limit=&offset=` | 本人事件、随笔、total、timezoneOffsetMinutes |
| PUT / DELETE | `/events/:id/note` | 保存/删除本人随笔 |
| GET | `/milestone` | 次数、曲目/歌手数、日期/连续天数、小时/月分布、最常播放曲目 |
| GET / POST | `/cards` | 分页读取/生成本人卡片 |
| GET / DELETE | `/cards/:id` | 读取/删除本人卡片 |
| GET / POST | `/posts` | 成员广场/显式发布本人卡片 |
| GET | `/posts/mine` | 本人分享 |
| GET / DELETE | `/posts/:id` | 成员可读详情/本人删除；详情带站点偏移及评论删除能力 |
| PUT / DELETE | `/posts/:id/like` | 点赞/取消点赞 |
| GET / POST | `/posts/:id/comments` | 分页读取/新增评论；每页最多 50 条 |
| DELETE | `/comments/:id` | 删除本人评论 |

默认站点偏移为 UTC+8（480 分钟）。时间轴、里程和详情返回偏移，前端不依赖浏览器所在地分组；服务构造参数支持验证后的偏移，不新增环境配置。

## 播放与生命周期

`player-core` 只增加可选的成功开播回调：`audio.play()` 成功且仍属于当前请求时才通知。App 负责调用足迹客户端；页面通过既有 MusicActions 播放或加入统一队列，不持有音频元素。后台或失败上报不会中断歌曲，退出会话取消在途上报。

同一用户、同来源、同曲 30 秒内去重；暂停恢复不新增记录。这是开播快照，不是精确收听计量：里程时长沿用原包的曲目全长累计，不表示实际听满的秒数；失败上报没有持久重试，不能作为可靠计费或审计日志。里程榜的播放项使用单曲时长，不能把累计时长再次上报。

足迹页访问后懒加载并保留实例。离页、切视图、卸载时取消请求并隔离迟到响应；后台开播 revision 在写操作结束后再消费，不打断随笔、分享或评论保存。Modal 复用现有焦点围栏/Escape，评论支持继续分页，窄屏保留横向功能导航。

## 接入边界

- 足迹的 `source` 只允许 `local` / `netease`，`sourceId` 为正整数；两种来源的相同数字 ID 不能混淆，同一首歌的不同来源分别记录。
- 卡片 SVG 只使用业务图形，不使用 `innerHTML`；下载后撤销 Object URL。样式使用现有 Design Tokens，保留原样式基线。
- 不新增 Audio、WebGL 或动画循环，不修改统一播放器、专辑墙和既有认证协议。
- 隔离验收使用真实 React、临时 SQLite、真实 Audio 与合成 WAV/模拟网易云 CDN。生产 Redis 实连、真实上游/VIP、公网部署以及已有非标准足迹表的升级迁移尚未验收；未做新的设备 CPU/GPU 或大数据压力基准，不宣称性能提升。
